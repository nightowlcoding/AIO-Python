IC3 Order CSV Renamer

Purpose:
- Rename timestamp-style order CSV files into readable names.
- Example: 2026042321051311079.csv -> Alice_2026-04-23_order.csv

Files in this folder:
- order_csv_renamer_gui.py : simple GUI app
- launch_order_csv_renamer.bat : launcher for Windows

How to use:
1. Double-click launch_order_csv_renamer.bat
2. Browse to a folder containing timestamp CSV files
3. Choose Alice or Kingsville
4. Preview renames
5. Apply renames

This folder is self-contained inside Inventory Control 3.
